# Comandos do agente

Use `rtk proxy <comando>` para comandos de shell. O bootstrap de um host vazio
é iniciado pelo operador conforme `bootstrap-dev.sh`; depois de preparar as
ferramentas, carregue `.steamzero-dev/env.sh` e mantenha RTK nos comandos.

Não altere autenticação, privilégios permanentes, boot ou instalações do host
para facilitar o desenvolvimento. Não peça senha até nova direção expressa.
Leia `AGENTS.md` e o ponto de entrada de recuperação antes de editar.
